`view: 'web'` on `createDocxEditor` and `DocxEditor.Root`, and `editor.setView`, show a document in Word's Web Layout: one page as wide as the viewport and as tall as the text, refused with the reason for a document with columns, a document grid, notes or floating content. `editor.setWriteAdmission(admission)` lets a host refuse what a local write would publish, across every lane that writes.
